CPTenderDocuments upload console

Upload once. Process the document end to end.

The upload creates an inactive source record in MongoDB, calls your OCR orchestration endpoint, and watches the same record until the pipeline marks it active and processed.

1. Upload document

The browser sends the file and metadata to the API. It never connects directly to MongoDB.

Lifecycle: create IsActive: false → call OCR endpoint → pipeline writes classification/OCR data → set IsActive: true and Status: "Processed".

2. Pipeline status

The UI polls the document record created by the upload.
